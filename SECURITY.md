# Politica di sicurezza

Questo repository contiene la scheda di presentazione del profilo GitHub: non
ospita software eseguibile. Le segnalazioni che lo riguardano sono quindi
limitate al contenuto pubblicato — per esempio un collegamento che punta a una
destinazione non attendibile.

## Versioni supportate

| Versione | Supportata |
| --- | --- |
| contenuto pubblicato su `main` | sì |

## Come segnalare un problema

**Non aprire una issue pubblica** per una vulnerabilità.

1. Vai nella scheda **Security** del repository interessato.
2. Scegli **Report a vulnerability** per aprire una segnalazione privata
   tramite le GitHub Security Advisories.

In alternativa puoi contattarmi da [@Shadowed1996](https://github.com/Shadowed1996).

Per vulnerabilità che riguardano gli **altri progetti**, usa la politica di
sicurezza del repository specifico.

## Cosa includere nella segnalazione

- Descrizione del problema e del suo impatto.
- Passi per riprodurlo.
- Eventuali collegamenti, schermate o riferimenti utili.

## Tempi di risposta

Primo riscontro entro **7 giorni**. Non intraprendo azioni legali nei confronti
di chi segnala in buona fede e senza divulgare il problema prima della correzione.

## Fuori ambito

- Segnalazioni automatiche di scanner senza un impatto dimostrato.
- Problemi dei servizi di terze parti citati, per esempio shields.io.
- Assenza di intestazioni di sicurezza su pagine ospitate da GitHub.
