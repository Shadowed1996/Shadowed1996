# Contribuire

Questo repository contiene la mia scheda di presentazione personale: il
contenuto è proprietario e **non sono aperti contributi esterni** al testo.

Resta però utile in due casi.

## Segnalare un errore

Se trovi un refuso, un collegamento rotto o un'informazione non più corretta,
apri una issue con il template **Segnalazione di un problema**. È il modo più
rapido: non serve una pull request.

## Se sei stato invitato a intervenire

Flusso di lavoro:

1. Crea un branch dedicato: `tipo/descrizione-breve`, per esempio
   `fix/collegamento-widgetchat`.
2. Un solo argomento per pull request.
3. Messaggi di commit in formato Conventional Commits, con la descrizione in
   italiano: `feat:`, `fix:`, `docs:`, `style:`, `refactor:`, `chore:`.

## Stile

- **Markdown**: intestazioni con `#`, elenchi con `-`, righe entro ~100 caratteri.
- **Italiano corretto**, con tutti gli accenti: è, à, ù, ì, ò, perché, così, già.
- **Nessun servizio esterno** oltre a shields.io con distintivi statici: niente
  contatori, statistiche generate al volo o script di terze parti che possano
  smettere di funzionare o tracciare chi legge.
- **Nessun indirizzo di posta elettronica** in chiaro nei file.

## Prima di aprire una pull request

- [ ] Il testo è corretto e i collegamenti funzionano.
- [ ] Non ho introdotto servizi esterni né dati personali.
- [ ] La descrizione della pull request spiega il perché della modifica.
